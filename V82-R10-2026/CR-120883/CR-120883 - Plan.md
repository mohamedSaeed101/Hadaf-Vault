# CR-120883 — User Transactions All Modules Report: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

> [!info] Sources
> CR text: [[CR-120883 - Source]] · Decisions (they override the CR): [[CR-120883 - Grilling Decisions]] · Previous draft (superseded, kept for reference): [[CR-120883 - Plan (draft v1)]]

> [!warning] Revised 2026-09-28 (after Phase 1–2 were built)
> - **No generator.** `Scripts/Tools/Generate_Vw_Acfx_UserTransactions.sql` is removed. The view is written and maintained by hand.
> - **Catalog slimmed** to the 5 columns read at runtime. The 17 `*Expr` / `FromClause` columns only fed the generator and are gone.
> - **One row per audit action**, not per document. The view is driven by `ACFX_Audit`: each Add / Edit / Cancel is a row with who (`ChangedByName`) and when (`ChangeDate`). The date range and the user filter apply to the action.
> - **`KeyValues` has three shapes** (`{"Id":39781}`, `39781`, `"39781"`). The view and the change function read all three.

**Goal:** A **new** report screen in Logistics that lists one row per audited action (Add / Edit / Cancel logged in `ACFX_Audit`) on the documents of 57 transaction types across Logistics, Cash, Construction and HR. The list is limited to the tenant's licensed applications. Each row gets a **Change Details** tab showing before and after values from `ACFX_Audit`, loaded when the row is expanded.

**Architecture:**
- **Database:**
  - A new catalog table, `ACFX_UserTransactionType`, holds one row per type: names, `ApplicationId` and the `ACFX_Audit` table name.
  - A hand-written SSDT view, `Vw_Acfx_UserTransactions`, reads `ACFX_Audit` and joins each action to its document through 57 `UNION ALL` branches, one per type, each carrying a literal type id.
  - An inline function, `ACFX_Rpt_UserTransactionChanges`, returns one type's audit history for one document.
- **AnalyticsReader:**
  - Serves the view through OData. Filtering happens on the server, from query options.
  - Serves the change history as a per-row detail endpoint.
  - Serves print/export for the report.
  - Every one of these paths is restricted to licensed applications.
- **Misc API:** serves the filter lookup lists, restricted to licensed applications.
- **Angular:** a new report module built on `report-grid-multi-request`. The Application picker decides which module's filters are shown.

**Tech stack:** SQL Server 2016 (SSDT `Sql130`, `OPENJSON`, no `STRING_AGG`) · ASP.NET Core 8, EF Core 8, OData 9 (AnalyticsReader) · MediatR 12 (Misc) · NUnit 3.13, FluentAssertions 5.10 (`Logistics.Application.Test`) · Angular 18, DevExtreme, ngx-translate

## Global Constraints

- **New report; the old one stays untouched.** Do not change `Vw_Lgx_UserTransactions`, `Vw_Lgx_UserTransactionsDetail`, `Lgx_TransactionsType`, `UserTransactionListReport` or the `user-transactions-report` route. (Q6a, Q6b, Q35)
- **Scope is 57 types, transactions only, never master data.** (Q27–Q34)
  - Logistics: the existing 20 types.
  - HR: 8 `IAuditedEntityBase` documents.
  - Cash: 14 audited documents.
  - Construction: 15 audited documents.
- **No new audit logging and no change to `ChangeTrackerExtensions`.** (Q29)
- **No schema change and no index on `ACFX_Audit`.** Change details are loaded only when a row is expanded. (Q7, Q11, Q25)
- **Permission stays 720 for everything:** OData, print, the Misc lookups and the route. The menu caption is the same as the old report. The internal report name is `User Transactions All Modules Report`. (Q6c, Q6d)
- **The server enforces licensing.** Every endpoint filters by the tenant's licensed applications. The UI is never the only gate. (Q26, CR §2.1)
- **`ApplicationId` values** are the `Acc_Applications` ids: Logistics **12**, HR **4**, Cash **7**, Construction **9**. These are **not** `HadafProductLicense.Product` ids; product id 12 is Concrete, not Logistics. (Q37)
- **Rows are audit actions.** The date range and the user filter apply to the action (`ChangeDate`, `ChangedById`), not to the document's own date or creator.
- **Transaction date** (a column, not the filter) is the document's own date. When a table has none, use the creation date. A missing number is left empty, not replaced with the id. (Q23, Q23b)
- **Approvals show as edits** of the status field. Field captions come from a caption table, falling back to the property name. Names are resolved for 13 key fields. (Q14, Q16, Q20)
- **Database conventions** (`AccFlex_Cloud_Database/CLAUDE.md` and memory):
  - DDL goes only in `dbo/` model files.
  - Reference data is an idempotent `MERGE` in `Scripts/ReferenceDataScripts/`, registered as `<None Include>`.
  - Reference-data scripts must contain no `GO` and no single quotes inside string values. The runner wraps each script in `exec('…')`.
  - Every new `.sql` file must be registered in the `.sqlproj`, or it is silently dropped.
- **Build commands:**
  - Database: VS 2022 MSBuild with `/p:VisualStudioVersion=17.0`, not `dotnet build`.
  - Backend: `-c Release`, because VS locks Debug. If `Logistics.API` is locked, pass `-p:BaseOutputPath=<scratchpad>/bin/`.
- **Tests:**
  - They go in `Logistics.Application.Test`, with a `ProjectReference` to `AnalyticsReader.Api`.
  - AnalyticsReader tests live in their own files. Never add `using AnalyticsReader.Api;` next to `using Logistics.API;`, because both define `Startup`. (Q8)
  - DB-backed failures that already exist are expected noise. Compare against a baseline.
- **Angular:**
  - New i18n keys go in `src/assets/i18n/{ar-EG,en-US}/shared.json` under `ODATAREPORTS`. Grep first: a duplicate key silently overrides the earlier one.
  - Type-check through `tsconfig.verify.json`, because a full `ng build` of `logistics` is broken by a missing `projects/logistics/src/main.ts`.
- **Report grid conventions:**
  - Columns ending in `Id` or `Hidden` are auto-hidden.
  - `*FirstLanguage` columns show in Arabic and `*SecondLanguage` in English.
  - Captions come from `ODATAREPORTS.<dataField>`.

## Decisions This Plan Makes (flag to the PO)

| # | Decision | Why |
|---|---|---|
| P1 | Logistics keeps **type ids 1–20**, the same as `Lgx_TransactionsType`. The other modules use blocks: **HR 401–408, Cash 701–714, Construction 901–915** (prefix = ApplicationId) | The Logistics "lines" tab can reuse `Vw_Lgx_UserTransactionsDetail` as-is, and each block leaves room to grow |
| P2 | All filters travel as **query options**. The server applies them in one tested class, `UserTransactionsAllModulesFilter`, which both the grid and print use | One implementation means the grid and print can't drift apart. This follows the `FinancialCustodyTransactionReport` pattern |
| P3 | **Within a module, filters are OR'd** for Logistics (sales, purchase, inventory) and Cash (treasury, bank), and **AND'd** for HR (department, branch) | A Logistics or Cash row carries only one of those kinds. An HR row carries both |
| P4 | When a filter is used, rows whose filter column is **NULL are excluded** | Affects types with no per-document value: `PR_EmployeeAllowance`, `PR_DailyAllowance` (department/branch sit on detail rows), `Cnt_CostDistribution` and `Cnt_WorkerCostDistribution` (project sits on detail rows), and Cash requests with no treasury or bank |
| P5 | Money transfer: treasury = `SourceSafeId`, bank = `SourceBankId` | The table has both source and destination columns |
| P6 | The Application picker lists only licensed applications. The treasury, bank, project, department and branch lists are **not** narrowed to the current user | Q26 interpretation |
| P7 | The main grid key is `RowKeyHidden` = the `AuditId` | One document has several action rows, and `TransactionId` repeats across types |
| P8 | `ChangedById` comes from matching `ACFX_Audit.UserName` to `Acc_User.UserName` (first match) | The audit log stores only the user name |

## Known Gaps (tell the customer)

- Documents not audited are not in the report: most of HR (PayingSalary, AttendanceSheet, Advance, Penalty, …), `ConstractorContract` and `TransferSettlement`. (Q29)
- Deletes are never audited.
- An edit that changes only a document's lines records nothing.
- Saves made through Logistics read-side copies are not audited.
- History starts when the cloud version started writing `ACFX_Audit`. Older documents show "not available".
- Desktop AccFlex_ERP edits are not in `ACFX_Audit`. (Q5: cloud only)
- **General Settings move:** CR §4.1-7 and the §4.5.2 redirect are not in the decisions. This plan keeps the new report in the Logistics app. A tenant without a Logistics license can't reach it until a move is decided.

### Task 1: Type catalog `ACFX_UserTransactionType` + seed

**Files:**

**Interfaces:**
- Produces: table `dbo.ACFX_UserTransactionType`, keyed by `UserTransactionTypeId INT`, with 57 rows and `ApplicationId ∈ {12, 4, 7, 9}`.
- The catalog holds **only what is read at runtime**:

| Column | Meaning | Read by |
|---|---|---|
| `UserTransactionTypeId` | Type id. Logistics 1–20 (same as `Lgx_TransactionsType`), HR 401–408, Cash 701–714, Construction 901–915 | The view (each branch hard-codes its id), the type filter, the change function's parameter |
| `Name` / `NameSecondLanguage` | Arabic / English type name | The view's `TransactionsType*Language` columns (type name + optional sub-type) |
| `ApplicationId` | Owning module, FK to `Acc_Applications`: 12 Logistics, 4 HR, 7 Cash, 9 Construction | The view's `Application*` columns, the module filter, licensing |
| `AuditTableName` | The table name as written in `ACFX_Audit.TableName` | The view (`Events`) and `ACFX_Rpt_UserTransactionChanges` join `ACFX_Audit` on it |

- How each type reads its source table (id, number, date, users, sub-type, filter columns) lives **only in the view** (Task 2). There are no SQL-expression columns and no generator.

```sql
),

            CASE WHEN n.[type] IN (4, 5) OR o.[type] IN (4, 5) THEN 0 ELSE 1 END AS IsComparable ,
            o.[value]                                                       AS OldValue ,
            n.[value]                                                       AS NewValue
    FROM    AuditEvents e
            CROSS APPLY OPENJSON(e.NewValues) n
            OUTER APPLY ( SELECT TOP (1) oj.[value], oj.[type] FROM OPENJSON(e.OldValues) oj WHERE oj.[key] = n.[key] ) o
    WHERE   e.ChangeActionId IN (2, 3)
      AND   n.[key] NOT IN (N'LastModifiedOn', N'LastModifiedById', N'CreatedOn', N'CreatedById', N'GuidNumber', N'LastSyncDate', N'RowVersion', N'TimeStamp')
      AND   ISNULL(o.[value], N'<null>') <> ISNULL(n.[value], N'<null>')
),
AllRows AS
(
    -- Add / Cancel event rows (one per audit event, no field)
    SELECT  e.AuditId , e.ChangeDate , e.ChangedByName , e.ChangeActionId ,
            CAST(N'' AS NVARCHAR(4000)) AS FieldName ,
            CAST(NULL AS NVARCHAR(MAX)) AS OldValue , CAST(NULL AS NVARCHAR(MAX)) AS NewValue ,
            CAST(NULL AS NVARCHAR(400)) AS Note
    FROM    AuditEvents e
    WHERE   e.ChangeActionId IN (1, 3)
    UNION ALL
    -- Field rows: before / after, with names resolved for the 13 lookup fields
    SELECT  f.AuditId , f.ChangeDate , f.ChangedByName , f.ChangeActionId , f.FieldName ,
            CASE WHEN f.IsComparable = 1 THEN COALESCE(oldName.Name, f.OldValue) END ,
            CASE WHEN f.IsComparable = 1 THEN COALESCE(newName.Name, f.NewValue) END ,
            CASE WHEN f.IsComparable = 0 THEN
                 CASE WHEN @IsArabic = 1 THEN N'تم تعديل بنود الحركة - تفاصيل المقارنة غير متاحة'
                      ELSE N'Line items changed - comparison not available' END END
    FROM    FieldChanges f
            LEFT JOIN dbo.ACFX_UserTransactionFieldLookup fl ON fl.[FieldName] = f.FieldName
            OUTER APPLY dbo.ACFX_ResolveLookupName(fl.[LookupKindId], f.OldValue, @IsArabic) oldName
            OUTER APPLY dbo.ACFX_ResolveLookupName(fl.[LookupKindId], f.NewValue, @IsArabic) newName
    UNION ALL
    -- No audit history at all (document older than audit logging, or never edited through the cloud)
    SELECT  0 , CAST(NULL AS DATETIME) , CAST(NULL AS NVARCHAR(256)) , 0 , N'' ,
            CAST(NULL AS NVARCHAR(MAX)) , CAST(NULL AS NVARCHAR(MAX)) ,
            CASE WHEN @IsArabic = 1 THEN N'تفاصيل التعديل (القيمة قبل / بعد) غير متاحة لهذه الحركة'
                 ELSE N'Change details (old / new value) are not available for this transaction' END
    WHERE   NOT EXISTS (SELECT 1 FROM AuditEvents)
)
SELECT  ROW_NUMBER() OVER (ORDER BY r.AuditId, r.FieldName)                 AS RowNo ,
        r.AuditId ,
        r.ChangeDate ,
        r.ChangedByName ,
        r.ChangeActionId ,
        CASE r.ChangeActionId
             WHEN 0 THEN CASE WHEN @IsArabic = 1 THEN N'غير متاح' ELSE N'Not available' END
             WHEN 1 THEN CASE WHEN @IsArabic = 1 THEN N'إضافة'   ELSE N'Add' END
             WHEN 2 THEN CASE WHEN @IsArabic = 1 THEN N'تعديل'   ELSE N'Edit' END
             WHEN 3 THEN CASE WHEN @IsArabic = 1 THEN N'إلغاء'   ELSE N'Cancel' END
        END                                                                 AS ChangeAction ,
        r.FieldName ,
        NULLIF(COALESCE(CASE WHEN @IsArabic = 1 THEN c.[Caption] ELSE c.[CaptionSecondLanguage] END, r.FieldName), N'') AS FieldCaption ,
        r.OldValue ,
        r.NewValue ,
        r.Note
FROM    AllRows r
        LEFT JOIN dbo.ACFX_UserTransactionFieldCaption c ON c.[FieldName] = r.FieldName;
```

```csharp
            [CashControl] = new[] { Product.StoreWeb.ReferenceName, Product.Store.ReferenceName },
            [Construction] = new[] { Product.ConstructionWeb.ReferenceName, Product.Construction.ReferenceName },

        public static IReadOnlyList<int> LicensedApplicationIds(IEnumerable<string>? productNames)
        {
            var licensed = new HashSet<string>(productNames ?? Array.Empty<string>(), StringComparer.OrdinalIgnoreCase);

                .Where(applicationId => ApplicationProducts[applicationId].Any(licensed.Contains))

        }
```

```csharp
using AnalyticsReader.Api.Reports.AngularReportHelper;

namespace AnalyticsReader.Api.Helpers.UserTransactions
{
    public sealed record UserTransactionsAllModulesCriteria(
        DateTime FromDate,
        DateTime ToDate,
        IReadOnlyCollection<int> UserIds,
        int? ApplicationId,
        IReadOnlyCollection<int> TransactionTypeIds,
        IReadOnlyCollection<int> InventoryManagementIds,
        IReadOnlyCollection<int> SalesOrganizationIds,
        IReadOnlyCollection<int> PurchaseOrganizationIds,
        IReadOnlyCollection<int> TreasuryIds,
        IReadOnlyCollection<int> BankIds,
        IReadOnlyCollection<int> ProjectIds,
        IReadOnlyCollection<int> DepartmentIds,
        IReadOnlyCollection<int> BranchIds)
    {
        /// <summary>Builds criteria from report query options; null when the date range is missing or invalid.</summary>
        public static UserTransactionsAllModulesCriteria? FromQueryOptions(Func<string, string?> getValue)
        {
            var fromDate = Clean(getValue("fromDate"));
            var toDate = Clean(getValue("toDate"));
            if (string.IsNullOrWhiteSpace(fromDate) || string.IsNullOrWhiteSpace(toDate))
                return null;

            DateTime from, to;
            try
            {
                (from, to) = ReportExtensions.ParseUtcDateRange(fromDate, toDate);
            }
            catch (Exception exception) when (exception is ArgumentException or FormatException)
            {
                return null;
            }

            return new UserTransactionsAllModulesCriteria(
                from,
                to,
                Ids(getValue("userIds")),
                int.TryParse(Clean(getValue("applicationId")), out var applicationId) ? applicationId : null,
                Ids(getValue("transactionTypeIds")),
                Ids(getValue("inventoryManagementIds")),
                Ids(getValue("salesOrganizationIds")),
                Ids(getValue("purchaseOrganizationIds")),
                Ids(getValue("treasuryIds")),
                Ids(getValue("bankIds")),
                Ids(getValue("projectIds")),
                Ids(getValue("departmentIds")),
                Ids(getValue("branchIds")));
        }

        private static string? Clean(string? value) => value?.Trim().Replace("'", "").Replace("\"", "");

        private static IReadOnlyCollection<int> Ids(string? value) =>
            (Clean(value) ?? string.Empty)
                .Split(',', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries)
                .Select(part => int.TryParse(part, out var id) ? id : (int?)null)
                .Where(id => id.HasValue)
                .Select(id => id!.Value)
                .ToList();
    }
}
```

```csharp
using AnalyticsReader.Api.ODataViews.UserTransactionsAllModules;
using SharedKernel.Logic.AccApplication;

namespace AnalyticsReader.Api.Helpers.UserTransactions
{
    public static class UserTransactionsAllModulesFilter
    {
        public static IQueryable<UserTransactionsAllModules> Apply(this IQueryable<UserTransactionsAllModules> query,
            UserTransactionsAllModulesCriteria criteria,
            IReadOnlyCollection<int> licensedApplicationIds)
        {
            query = query.Where(x => licensedApplicationIds.Contains(x.ApplicationId));

            query = query.Where(x => x.ChangeDate >= criteria.FromDate && x.ChangeDate <= criteria.ToDate);

            if (criteria.UserIds.Count > 0)
                query = query.Where(x => x.ChangedById.HasValue && criteria.UserIds.Contains(x.ChangedById.Value));

            if (criteria.ApplicationId.HasValue)
                query = query.Where(x => x.ApplicationId == criteria.ApplicationId.Value);

            if (criteria.TransactionTypeIds.Count > 0)
                query = query.Where(x => criteria.TransactionTypeIds.Contains(x.TransactionTypeId));

            // Logistics: a row carries one org kind, so the selected kinds are OR'ed (same as the old report).
            if (criteria.SalesOrganizationIds.Count > 0 || criteria.PurchaseOrganizationIds.Count > 0 || criteria.InventoryManagementIds.Count > 0)
                query = query.Where(x => x.ApplicationId != AccApplicationLicense.Logistics ||
```

```csharp
        [Route("odata/UserTransactionsAllModules")]
        [HttpGet]
        [ProducesDefaultResponseType]
        [ProducesResponseType(StatusCodes.Status200OK)]
        [EnableQuery(AllowedQueryOptions = AllowedQueryOptions.All,
            MaxExpansionDepth = (int)MaxExpansionDepth.LogisticsMaxExpansionDepth)]
        [PermissionModuleId((int)ModuleIds.UserTransactions)]
        [Authorize(Policy = SharedConstants.ViewPolicy)]
        public ActionResult UserTransactionsAllModules()
        {
            var criteria = UserTransactionsAllModulesCriteria.FromQueryOptions(name => Request.Query[name].FirstOrDefault());
            if (criteria is null)
                return Ok(Enumerable.Empty<UserTransactionsAllModules>().AsQueryable());

            return Ok(context.UserTransactionsAllModules.AsNoTracking().Apply(criteria, LicensedApplicationIds()));
        }

        [Route("odata/UserTransactionChanges")]
        [HttpGet]
        [ProducesDefaultResponseType]
        [ProducesResponseType(StatusCodes.Status200OK)]
        [EnableQuery(AllowedQueryOptions = AllowedQueryOptions.All,
            MaxExpansionDepth = (int)MaxExpansionDepth.LogisticsMaxExpansionDepth)]
        [PermissionModuleId((int)ModuleIds.UserTransactions)]
        [Authorize(Policy = SharedConstants.ViewPolicy)]
        public ActionResult UserTransactionChanges(int userTransactionTypeId, int transactionId)
        {
            if (!IsTypeLicensed(userTransactionTypeId))
                return Ok(Enumerable.Empty<UserTransactionChange>().AsQueryable());

            var isArabic = _userSession.IsDefaultRequestCulture;
            return Ok(context.UserTransactionChanges.FromSqlInterpolated(
                $"SELECT * FROM dbo.ACFX_Rpt_UserTransactionChanges({userTransactionTypeId}, {transactionId}, {isArabic})").AsNoTracking());
        }

        [Route("odata/UserTransactionLines")]
        [HttpGet]
        [ProducesDefaultResponseType]
        [ProducesResponseType(StatusCodes.Status200OK)]
        [EnableQuery(AllowedQueryOptions = AllowedQueryOptions.All,
            MaxExpansionDepth = (int)MaxExpansionDepth.LogisticsMaxExpansionDepth)]
        [PermissionModuleId((int)ModuleIds.UserTransactions)]
        [Authorize(Policy = SharedConstants.ViewPolicy)]
        public ActionResult UserTransactionLines(int userTransactionTypeId, int transactionId)
        {
            // Lines exist only for the 20 Logistics types (ids 1-20, identical to Lgx_TransactionsType).
            var isLogisticsType = userTransactionTypeId is >= 1 and <= 20 &&
                                  LicensedApplicationIds().Contains(AccApplicationLicense.Logistics);

            return Ok(context.UserTransactionLines.AsNoTracking().Where(x =>
                isLogisticsType && x.TransactionTypeId == userTransactionTypeId && x.TransactionId == transactionId));
        }

        private IReadOnlyCollection<int> LicensedApplicationIds() =>
            AccApplicationLicense.LicensedApplicationIds(HttpContext.Features.Get<Tenant>()?.ProductNameList).ToList();

        private bool IsTypeLicensed(int userTransactionTypeId)
        {
            var applicationId = userTransactionTypeId switch
            {
                >= 1 and <= 20 => AccApplicationLicense.Logistics,
                >= 401 and <= 499 => AccApplicationLicense.HumanResources,
                >= 701 and <= 799 => AccApplicationLicense.CashControl,
                >= 901 and <= 999 => AccApplicationLicense.Construction,
                _ => 0
            };
            return LicensedApplicationIds().Contains(applicationId);
        }
```

```csharp
using MediatR;
using Microsoft.EntityFrameworkCore;
using SharedKernel.Data;
using SharedKernel.Logic.AccApplication;
using SharedKernel.Logic.Tenants;

namespace Misc.Application.UserTransactionLookups
{
    public class GetUserTransactionLookupQuery : IRequest<List<UserTransactionLookupItemDto>>
    {
        public UserTransactionLookupKind Kind { get; set; }
        public int? ApplicationId { get; set; }
    }

    public class GetUserTransactionLookupQueryHandler : IRequestHandler<GetUserTransactionLookupQuery, List<UserTransactionLookupItemDto>>
    {
        private readonly SharedKernelContext context;
        private readonly ITenantProvider tenantProvider;

        public GetUserTransactionLookupQueryHandler(SharedKernelContext context, ITenantProvider tenantProvider)
        {
            this.context = context;
            this.tenantProvider = tenantProvider;
        }

        public async Task<List<UserTransactionLookupItemDto>> Handle(GetUserTransactionLookupQuery request, CancellationToken cancellationToken)
        {
            var licensed = AccApplicationLicense.LicensedApplicationIds(tenantProvider.GetTenant()?.ProductNameList);

            switch (request.Kind)
            {
                case UserTransactionLookupKind.Applications:
                    return Applications.Where(a => licensed.Contains(a.Id)).ToList();

                case UserTransactionLookupKind.TransactionTypes:
                    var types = await context.Database.SqlQuery<UserTransactionLookupItemDto>($@"
                        SELECT UserTransactionTypeId AS Id, Name, NameSecondLanguage, ApplicationId
                        FROM dbo.ACFX_UserTransactionType")
                        .ToListAsync(cancellationToken);
                    return types
                        .Where(t => licensed.Contains(t.ApplicationId!.Value))
                        .Where(t => !request.ApplicationId.HasValue || t.ApplicationId == request.ApplicationId)
                        .OrderBy(t => t.ApplicationId).ThenBy(t => t.Id)
                        .ToList();

                case UserTransactionLookupKind.Treasuries when licensed.Contains(AccApplicationLicense.CashControl):
                    return await context.Database.SqlQuery<UserTransactionLookupItemDto>($@"
                        SELECT StoreId AS Id, StoreCode AS Name, StoreCode AS NameSecondLanguage, CAST(NULL AS INT) AS ApplicationId
                        FROM dbo.Saf_Store ORDER BY StoreCode").ToListAsync(cancellationToken);

                case UserTransactionLookupKind.Banks when licensed.Contains(AccApplicationLicense.CashControl):
                    return await context.Database.SqlQuery<UserTransactionLookupItemDto>($@"
                        SELECT BankId AS Id, BankName AS Name, BankName AS NameSecondLanguage, CAST(NULL AS INT) AS ApplicationId
                        FROM dbo.Saf_Bank ORDER BY BankName").ToListAsync(cancellationToken);

                case UserTransactionLookupKind.Projects when licensed.Contains(AccApplicationLicense.Construction):
                    return await context.Database.SqlQuery<UserTransactionLookupItemDto>($@"
                        SELECT ProjectId AS Id, CAST(ProjectName AS NVARCHAR(500)) AS Name, CAST(ProjectNumber AS NVARCHAR(500)) AS NameSecondLanguage, CAST(NULL AS INT) AS ApplicationId
                        FROM dbo.Cnt_Project ORDER BY ProjectNumber").ToListAsync(cancellationToken);

                case UserTransactionLookupKind.Departments when licensed.Contains(AccApplicationLicense.HumanResources):
                    return await context.Database.SqlQuery<UserTransactionLookupItemDto>($@"
                        SELECT DepartmentId AS Id, DepartmentName AS Name, DepartmentName AS NameSecondLanguage, CAST(NULL AS INT) AS ApplicationId
                        FROM dbo.PR_Department ORDER BY DepartmentName").ToListAsync(cancellationToken);

                case UserTransactionLookupKind.Branches when licensed.Contains(AccApplicationLicense.HumanResources):
                    return await context.Database.SqlQuery<UserTransactionLookupItemDto>($@"
                        SELECT BranchId AS Id, BranchName AS Name, BranchNameSecondLanguage AS NameSecondLanguage, CAST(NULL AS INT) AS ApplicationId
                        FROM dbo.Acc_Branch ORDER BY BranchName").ToListAsync(cancellationToken);

                default:
                    return new List<UserTransactionLookupItemDto>();
            }
        }

        {
```

```ts
import { HttpClient } from '@angular/common/http';
import { Injectable, inject } from '@angular/core';
import { Observable, defer } from 'rxjs';
import { configStorageGetter } from 'src/app/shared/utils';

export interface UserTransactionLookupItem {
  Id: number;
  Name: string;
  NameSecondLanguage: string | null;
  ApplicationId: number | null;
}

export type UserTransactionLookupKind =
  | 'Applications'
  | 'TransactionTypes'
  | 'Treasuries'
  | 'Banks'
  | 'Projects'
  | 'Departments'
  | 'Branches';

@Injectable()
export class UserTransactionLookupService {
  private readonly http = inject(HttpClient);

  /** Not cached: every open reflects the tenant's current license (CR §4.5.2-1). */
  get(kind: UserTransactionLookupKind, applicationId?: number | null): Observable<UserTransactionLookupItem[]> {
    return defer(() => {
      const miscApiUrl = (configStorageGetter()?.apiUrls?.miscapi ?? '').trim().replace(/\/+$/, '');
      const params: Record<string, string> = applicationId ? { applicationId: String(applicationId) } : {};
      return this.http.get<UserTransactionLookupItem[]>(`${miscApiUrl}/UserTransactionLookup/${kind}`, { params });
    });
  }
}
```

```ts
        catchError((err) => {
          this.errorHandler.handleError(err);
          return EMPTY;

      )
      .subscribe(() => this.updateQueryOptions());

    this.transactionTypes$ = this.lookup('TransactionTypes', applicationId);

    this.banks$ = applicationId === ApplicationIds.CashControl ? this.lookup('Banks') : of([]);
    this.projects$ = applicationId === ApplicationIds.Construction ? this.lookup('Projects') : of([]);
    this.departments$ = applicationId === ApplicationIds.HumanResources ? this.lookup('Departments') : of([]);
    this.branches$ = applicationId === ApplicationIds.HumanResources ? this.lookup('Branches') : of([]);

      map((items: UserTransactionLookupItem[]) =>
        items.map((item) => ({
          Id: item.Id,
          Name: this.isRtlEnabled ? item.Name : (item.NameSecondLanguage ?? item.Name)
        }))
      ),
      catchError((err) => {
        this.errorHandler.handleError(err);
        return of([]);
      })
    );
  }

  /** Query-option names must match UserTransactionsAllModulesCriteria.FromQueryOptions on the API. */
  private updateQueryOptions(): void {
    const v = this.reportForm.value;
    const ids = (value: number[] | null): string | undefined => (value?.length ? value.join(',') : undefined);

    this.HeaderQueryOptions['fromDate'] = new Date(v.FromDate).toISOString();
    this.HeaderQueryOptions['toDate'] = new Date(v.ToDate).toISOString();
    this.HeaderQueryOptions['userIds'] = ids(v.UsersIds);
    this.HeaderQueryOptions['applicationId'] = v.ApplicationId ?? undefined;
    this.HeaderQueryOptions['transactionTypeIds'] = ids(v.TransactionTypeIds);
    this.HeaderQueryOptions['salesOrganizationIds'] = ids(v.SalesOrgsIds);
    this.HeaderQueryOptions['purchaseOrganizationIds'] = ids(v.PurchaseOrgsIds);
    this.HeaderQueryOptions['inventoryManagementIds'] = ids(v.InventoryMangsIds);
    this.HeaderQueryOptions['treasuryIds'] = ids(v.TreasuryIds);
    this.HeaderQueryOptions['bankIds'] = ids(v.BankIds);
    this.HeaderQueryOptions['projectIds'] = ids(v.ProjectIds);
    this.HeaderQueryOptions['departmentIds'] = ids(v.DepartmentIds);
    this.HeaderQueryOptions['branchIds'] = ids(v.BranchIds);
  }

  /** Same default as the old report: the user's default sales org (visible while Logistics is selected). */
  private setDefaultValues(): void {
    this.subs.sink = this.logisticsStaticResourcesService.userSubject.subscribe((user) => {
      if (user?.DefaultSalesOrganizationId && this.selectedApplicationId === ApplicationIds.Logistics) {
        this.reportForm.controls.SalesOrgsIds.setValue([user.DefaultSalesOrganizationId]);
      }
    });
  }
}
```

## Risks & Mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| A view branch names a wrong column | Medium | The SSDT build catches it as `SQL71501` |
| `AuditTableName` spelling differs from `ACFX_Audit.TableName` | Medium | Discovery query (Task 1 Step 6) |
| Expanding a row is slow because `ACFX_Audit` has no index | Medium (depends on table size) | Measure it (Task 3 Step 10). If it misses the target, escalate to the PO. Q11 decides whether an index is added |
| The view and the catalog get out of step (a type added in only one) | Low | Header comment and the branch-count check (Task 2 Step 4e) |
| The grid is slow because the view reads all of `ACFX_Audit` (no index, date filter on a converted value) | Medium (depends on table size) | Measure it (Task 2 Step 4d). If it misses the target, escalate: an index on `ACFX_Audit (TableName, DateTime)` needs a new decision (Q11) |
| Old audit rows use a different `KeyValues` shape | Handled | The view and the function read `{"Id":n}`, `n` and `"n"` (Task 2 Step 4b) |
| The AnalyticsReader reference breaks `Logistics.Application.Test` (second `Startup`, duplicate `appsettings.json`) | Low–Medium | Baseline before and after (Task 4 Steps 1 and 6). If the counts change, stop and raise it. Don't work around it |
| The deprecated `report-grid-multi-request` is removed later | Low | It is still in use (`bank-guarantee-report`). Migrating is a separate task |
| 1:N filters (allowances, cost distributions) surprise users | Medium | P4, shown to the PO. The rows appear when no filter is set |
