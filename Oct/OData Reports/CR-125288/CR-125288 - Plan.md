Parameter rules:
- Dates are sent as `yyyy-MM-dd`. The backend passes from = start of day and to = end of day (23:59:59.997, as the legacy rpt constructors do).
- Id lists are CSV. An empty string or `'null'` means NULL, which means all.
- `viewAll` is `true` / `false`.

### Columns (every non-key column is nullable in C#; `RowNo` is `long`)
- **R1 `Acc_PeriodBalanceReport`:**
  - Columns: `RowNo`, `AccountBalanceId` int, `AccountId` int, `AccountNo` nvarchar, `AccountName` nvarchar, `CurrencyName`, `CurrencyNameArabic`, `CurrencyFactor` decimal(19,7), `Debit`, `Credit`, `DebitLocal`, `CreditLocal` (money→decimal), `CreatedDate`, `ModifiedDate` datetime.
  - Row order: `RowNo = ROW_NUMBER() OVER (ORDER BY AccountNo, AccountBalanceId)`.
- **R2 `Acc_EstimatedBudgetPeriodReport`:**
  - Columns: `RowNo`, `AccountId`, `AccountNo`, `AccountName`, `OpenningCredit`, `OpenningDebit`, `PeriodCredit`, `PeriodDebit`, `OpenningBalance`, `PeriodBalance`, `Budget`, `Deviation`, `DeviationPercent` (decimals).
  - Row order: `ORDER BY AccountNo`.
- **R3 `Acc_EstimatedBudgetByMonthReport`:**
  - Columns: `RowNo`, `AccountId`, `AccountNo`, `AccountName`, `Mnth` int, `MonthName` nvarchar (`Jan`..`Dec`), `MonthNameArabic` (`يناير`..`ديسمبر`), `Budget`, `PeriodBalance`, `Deviation`, `DeviationPercent`.
  - Row order: `ORDER BY AccountNo, Mnth`.
- **R4 `Acc_EstimatedBudgetByDayReport`:**
  - Columns: `RowNo`, `AccountId`, `AccountNo`, `AccountName`, `DayDate` date, `Budget`, `PeriodBalance`, `Deviation`, `DeviationPercent`.
  - Row order: `ORDER BY AccountNo, DayDate`.
