# CR-125292 — Plan: payroll salary reports to OData

Method: `mvc-to-odata-report-migration` (data first, then layout), inside the `onboard-ticket` spine. Facts: [[CR-125292 - Source]].

## Size: L

About 60 files across 3 repos (DB ~17, Cloud_ERP ~26, Front ~19), new TVFs + API + front, plus layout seeds. No schema change to existing tables.

## Deviation from the skill

The skill targets `report-grid [printOnlyMode]="true"`. This ticket asks for on-screen filter / sort / group / export, so the target is the interactive `report-grid` (as in `cr125294`), pending Q2. The skill's data-fidelity rules apply unchanged.
