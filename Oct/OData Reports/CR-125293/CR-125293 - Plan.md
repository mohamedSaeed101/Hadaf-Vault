### 1. EmployeesSalariesItems — ModuleId 548 — route `employees-salaries-items-report`
- Legacy: RPT\HR\EmployeesFinancials\dsEmployeeFinance.xsd (`PR_Emp_Income`), action `EmployeesFinancials(employeesIds)`.
- TVF `PR_EmployeesSalariesItemsReport(@EmployeeIds NVARCHAR(MAX) = NULL, @InServiceFilter NVARCHAR(20) = NULL, @IsArabic BIT = 0)`
  - `@InServiceFilter`: NULL or 'All' = all; 'AllInService' = EndWork 0; 'AllTerminated' = EndWork 1. `@EmployeeIds` non-null = IN list. Otherwise legacy WHERE verbatim (incl. `IncomeEndDate IS NULL`).
  - Order: EmployeeId, Deduction, IncomeId.
- Columns: RowNo, EmployeeIncomeId, EmployeeId, IncomeId, IncomeCurrency, IncomeAmount, IncomeStartDate, IncomeTaxRoleId, SocialInsuranceRoleId, EmployeeInsuranceAmount, CompanyInsuranceAmount, CurrencyName, IncomeName, Deduction, EmployeeName, SocialInsuranceRole, DepartmentName, JobName, BranchName, DateOfWork, EmployeeNumber, IDNumber, ProjectName
- OData query params: `employeeids`, `inServiceFilter` (+ isArabic from the user's language, as other Payroll reports do).

### 2. PayCheck — ModuleId 550 — route `pay-check`
- Legacy: RPT\HR\EmployeesSalaries\dsSalariesReport.xsd (`Salaries`), action `EmployeesSalaries(employeesIds, isPaid, month, bankList)`.
- TVF `PR_PayCheckReport(@Month INT, @Year INT, @EmployeeIds NVARCHAR(MAX) = NULL, @BankIds NVARCHAR(MAX) = NULL, @IsPaid BIT = NULL, @SecurityLevel INT)`
  - **Fix**: `@IsPaid` NULL = all, else `Pr_PayingSalaries.IsPaid = @IsPaid` (legacy ignored the radio).
  - Order: EmployeeId (legacy ORDER BY).
- Columns: RowNo, EmployeeId, EmployeeNumber, EmployeeName, EmployeeArabicName, BranchName, DepartmentName, ProjectName, JobName, BankName, CurrencyName, CurrencyNameArabic, EmployeeSalary, IsPaid
- OData query params: `month` (yyyy-MM-dd, any day of the month), `employeeids`, `bankList`, `isPaid` ("true"/"false", omitted = all). Front radio: 1 All → omit, 2 Paid → true, 3 Not Paid → false.

  - Order: EmployeeId, Deduction, SalaryDetailId.
- Columns: RowNo, EmployeeId, EmployeeName, EmployeeNumber, BranchName, ProjectName, JobName, SalaryId, SalaryDetailId, EmployeeIncomeId, IncomeAmount, IncomeName, Deduction, EnglishLetter, SalaryMainId, Total, Remarks, InsuranceCompany, TotalAdditions, TotalDeductions, PostDate, Posted, SalaryYear, SalaryMonth, SalaryDate, Suspend, SalaryDetailSuspend, BankId, BankName, BankSEPA, BankAddress, BankBranch, BankCountry, BankAccountOwner, BankSwiftCode

### 4. InsuranceRegistration — ModuleId 552 — route `insurance-registration-report`
- Legacy: RPT\HR\InsuranceRegistration\dsInsuranceRegistration.xsd (`EmployeeInsurance`) + InsuranceRegistrationReport.cs:66-79, action `InsuranceRegistration(fromDate, toDate, employeesIds)`.
- TVF `PR_InsuranceRegistrationReport(@FromDate DATETIME, @ToDate DATETIME, @EmployeeIds NVARCHAR(MAX) = NULL, @SecurityLevel INT)` — legacy CTE + GROUP BY verbatim, except:
  - **Fix**: `emps.EndWorkingDate < GETDATE()` → `emps.EndWorkingDate >= CAST(GETDATE() AS DATE)` (keep employees whose end date has not passed).
  - **Fix/port of C#**: computed in SQL, only when the value > 0, else NULL (legacy blank):
    `TotalIncomeInt = FLOOR(TotalIncomeLocal)`, `TotalIncomeFraction = RIGHT('0' + CAST(FLOOR((TotalIncomeLocal - FLOOR(TotalIncomeLocal)) * 100) AS VARCHAR(2)), 2)` (truncation, as legacy Substring did), same for `InsuranceInt` / `InsuranceFraction` from TotalInsuranceLocal. Int columns as BIGINT, fraction as NVARCHAR(2).
  - Order: EmployeeName.
- Columns: RowNo, InsuranceNum, EmployeeName, EmployeeArabicName, Gender, IDNumber, StringInsuranceNum, StringIDNumber, WorkDate, WorkDateDay, WorkDateMonth, WorkDateYear, DateOfWork, DateOfWorkDay, DateOfWorkMonth, DateOfWorkYear, SocialInsuranceStartDate, SocialInsuranceStartDateDay, SocialInsuranceStartDateMonth, SocialInsuranceStartDateYear, TotalIncomeLocal, TotalInsuranceLocal, InsuranceSubscriptionFee, TotalIncomeInt, TotalIncomeFraction, InsuranceInt, InsuranceFraction
- OData query params: `fromDate`, `toDate` (yyyy-MM-dd), `employeeids`.

### 5. EmployeeBonus — ModuleId 771 — route `employee-bonus-report`
- Legacy: RPT\Accounting\EmployeeBonus\dsEmployeeBonus.xsd (`dtEmployeeBonus`), action `EmployeeBonusReport(fromDate, toDate, employeeIds)` (the HR\EmployeeBonus copy is unused).
- TVF `PR_EmployeeBonusReport(@FromDate DATETIME, @ToDate DATETIME, @EmployeeIds NVARCHAR(MAX) = NULL, @SecurityLevel INT, @IsArabic BIT = 0)` — legacy SQL verbatim; backend passes toDate as day end (legacy `AddDays(1).AddSeconds(-1)`).

- Columns: RowNo, SerialNumber, EmployeeId, EmployeeNumber, EmployeeName, JobName, EmployeeBonusId, BonusId, BonusName, BonusTypeId, BonusDate, BonusValueTypeName, BonusCurrencyId, CurrencyName, CurrencyEnglishLetter, CurrencyArabicLetter, BonusAmount, BounsTotalValue, Description, IsPaid, IsPaidStr
